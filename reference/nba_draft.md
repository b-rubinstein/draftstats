# NBA Draft Data and Career Per-Game Statistics

A dataset of NBA data from 1989 to 2021, with one row per drafted player
and their career per-game statistics.

## Usage

``` r
nba_draft
```

## Format

\## \`nba_draft\` A data frame with 1,922 rows and 9 columns:

- player_name:

  Player's name

- team_abbreviation:

  Team that drafted the player

- college:

  Name of college player attended

- draft_year:

  Year player was drafted

- draft_number:

  Overall number player was drafted

- gp:

  Number of games played throughout the player's career

- pts:

  Career average number of points scored per game

- reb:

  Career average number of rebounds per game

- ast:

  Career average number of assists per game

## Source

\<https://www.kaggle.com/datasets/mattop/nba-draft-basketball-player-data-19892021\>
